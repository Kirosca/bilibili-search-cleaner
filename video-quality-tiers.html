⚠️ 谨慎观看 高播低评避坑 播放 ≥ 2万 且 赞 > 0，赞播比 < 1.2% 且 藏播比 < 0.5%（限 时长 ≤ 15分钟 或未知，防长录像误判） 始终预警
🌱 样本较少 置信度保护 播放 < 3000 且未达到 💎 冷门宝藏 的破格门槛，数据样本不足暂不作定性评级 默认留白

⏱️ 时长加权归一化公式（防短视频虚高）

  • 以 5.0 分钟 为基准锚点（权重 1.00x）：权重 = min(2.0, max(0.4, √(时长分钟 / 5.0)))。
  • 短视频抑制：10 秒短片权重压至 0.40x，防止随手点赞挤占长篇神作席位。
  • 长视频奖励：20 分钟长片权重升至 2.00x，3.5% 赞播比即可等效 7.0%。

🔍 判定顺序与数据就绪机制

  • 优先顺序：样本较少/破格 → 谨慎观看 → 殿堂神作 → 爆款短片 → 冷门宝藏 → 硬核干货 → 高口碑 → 综合标杆 → 话题焦点/激辩/弹幕 → 稳健良作。
  • 防误判守卫：仅读取到 DOM 粗略数据时（缺少赞/藏）暂不评级，待接口全量统计就绪后自动补全。
