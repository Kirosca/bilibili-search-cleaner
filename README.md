# Bilibili 去掉搜索无关视频 (v3.0.0)

自动隐藏 Bilibili 搜索结果中不包含关键词的无关视频，支持 `@UP主` 定向筛选、`-排除词` 与 `#Tag` 专项筛选，彻底净化搜索体验。（内置 WBI 签名协议栈、无缝瀑布流与简繁归一化）

---

## 核心新特性 (v3.0.0)

- **无缝瀑布流引擎**：
  - 内置纯前端 WBI 签名算法（纯 JS MD5 + 64 字节字符混淆映射），脱离外部加密依赖直接与 B 站接口鉴权通信。
  - 响应式自适应栅格步长（根据当前物理列数 4~7 列自动按 6 行计算单页请求容量 24~42 条）。
  - 支持 `IntersectionObserver` 视口智能相交判定与连贯加载，彻底替代传统底部分页器。
- **实时检索条数动态反馈**：
  - 触底加载时动态展示已请求过的原始视频总数（如 `正在筛选... (已检索 60 条)`），提供直观的数据流反馈，彻底消除静态文本带来的假死卡顿感。
- **三大独立油猴菜单（默认全关，按需开启）**：
  - ⚓ **搜索筛选常驻**：维持搜索条件筛选面板始终展开。
  - 🔦 **聚光灯高亮模式**：开启时对符合目标条件的卡片进行全彩蓝青微光高亮，未匹配卡片半透明去色暗化；关闭时采用彻底的物理隐藏（`display: none`）。
  - 🌊 **无缝瀑布流**：流式滚动加载视频，并带右下角视口当前页码悬浮徽标。

---

## 筛选语法与安检规则

- **普通词**：标题必须包含该词（如 `数码`）。
- **`-排除词`**：标题中绝对不能出现该词，一票否决（如 `-开箱`）。
  - 发送给 B 站接口前会自动剥离排除词，最大化召回候选集合后再在本地进行二次物理过滤。
- **`#Tag` 标签筛选**：视频元数据与后台标签中必须包含该标签（如 `#评测`）。
- **`@UP主` 定向筛选**：投稿作者必须包含指定 UP 主名称（如 `@影视飓风`）。
- **全角与中文标点容错**：自动兼容中文输入法下的全角标点（如 `“ ”`、`＃`、`＠`、`－`）。
- **简繁归一化**：内置 OpenCC 繁简转换引擎，繁体与简体搜索词双向兼容。
