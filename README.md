# Bilibili 去掉搜索无关视频（fuse.js）

自动隐藏 Bilibili 搜索结果中不包含关键词的无关视频，支持 Fuse.js 模糊匹配、`@UP主` 定向筛选、`-排除词` 与 `#Tag` 专项筛选，净化搜索结果。（支持简繁中文归一化匹配与测试模式预览）

## 功能特性

- **哈尔滨工业大学《同义词词林（扩展版）》纯异素同义词与自定义映射引擎**：专治字面完全无重合的纯异素同义词（如“西红柿 $\leftrightarrow$ 番茄”、“土豆 $\leftrightarrow$ 马铃薯”、“自行车 $\leftrightarrow$ 单车”、“电脑 $\leftrightarrow$ 计算机”、“话筒 $\leftrightarrow$ 麦克风”、“发动机 $\leftrightarrow$ 引擎”等）：
  1. **内置词林 5,529 组严格等价概念**：全面覆盖日常果蔬农产、生活用品、数码硬件、交通工具、医药起居等核心领域，以 $0\text{ms}$ 极速哈希倒排完成词义等价放行；
  2. **用户自定义同义词热插拔配置**：在右下角悬浮胶囊点击齿轮图标（⚙️），可随时输入或修改自定义别名映射（如“深度求索=DeepSeek”、“老任=任天堂”），持久化保存于 `localStorage`，即改即生效；
  3. **测试模式透明溯源**：在测试模式下以青蓝色虚线边框与专属徽标清晰展示命中来源（如 `同义放行 [西红柿->番茄]`）。
- **官方实时搜索联想与相关词嗅探扩展（方案 A：Query Expansion）**：针对通用预训练嵌入模型无法识别的网络隐喻/流行梗（如“大肥鱼” $\rightarrow$ “DeepSeek”）、跨类别隐式关联（如“侏罗纪” $\rightarrow$ “恐龙”）、角色专有别称（如“崔斯特” $\rightarrow$ “英雄联盟/卡牌大师”），打通多路官方情报：
  1. **B 站官方 Suggest 实时联想接口**：毫秒级提取推荐短语及专有英文/数字特征词；
  2. **高频共现视频标签动态嗅探（Top Co-occurring Tags）**：从 B 站检索出的首屏及分页视频标签中自动挖掘高置信度共现领域概念；
  3. **检索响应纠错词 (suggest_keyword) 与相关搜索 (rq)**：实时补全关联词；
  扩词就绪后即刻以 0ms 词法速度自动放行，并在测试模式下以绿色徽标标注溯源（如 `联想放行 [deepseek]`、`联想放行 [恐龙]`）。
- **本地 bge-small-zh 密集向量语义模糊检索（Transformers.js）**：基于 `@xenova/transformers` 在端侧运行量化版 `bge-small-zh-v1.5` 嵌入模型，引入 BGE 官方非对称检索 Prompt 指令增强，结合长标题降噪切片与局部最大池化（Max-Pooling），按 0.60 余弦相似度阈值自动挽回因同义词、意译或长标题修饰词稀释导致错杀的相关视频。
- **IndexedDB 本地持久化与秒级载入**：利用浏览器原生 IndexedDB 搭建多级缓存适配器，彻底突破 Cache Storage 跨域响应头限制；二次访问实现 100% 本地极速加载，绝不重复下载。
- **Intl.Segmenter 原生中文分词 + Fuse.js 模糊匹配**：利用浏览器原生 `Intl.Segmenter`（0KB 额外体积）对长搜索词与卡片标题进行高精度拆词，将切词语料喂给 Fuse.js，既支持复合无空格长词切词匹配，又兼容错别字与同音近似容错。
- **测试模式（被过滤视频预览与局部切片溯源）**：右下角提供浮动统计胶囊。点击可实时在页面中展开被过滤视频，附带红色虚线高亮与具体相似度得分（如 `未命中关键词 (语义相似度: 0.42)`）；语义放行视频带有绿色虚线框并清晰展示具体命中来源（如 `语义放行 [走进远古恐龙时代] (0.71)`），悬停可临时恢复清晰度。
- **广告与推广卡片剔除**：精准屏蔽搜索流中的推广视频、商业广告及小火箭推荐卡片。
- **多词 OR 并列、官方高亮、【标签+分区名】与【视频简介】放行**：首屏通过扫描 `window.__pinia` 提取标签、分区与视频简介（翻页由 Fetch 持续拦截）；命中官方高亮、视频标题、标签/分区名或视频简介（OR 备选条件）均判定放行，并在测试模式下为简介单独命中的卡片标注来源（如 `简介命中`）。
- **高级语法过滤**：
  - `-排除词`：排除标题包含指定词汇的视频（保持严格精确匹配，避免误屏蔽）。
  - `#Tag`：基于视频标签分类进行严格筛选（指定标签须全部满足）。
  - `@UP主`：仅保留特定 UP 主发布的视频（作者须符合指定范围）。
- **简繁归一化**：内置 OpenCC 繁简转换引擎，繁体与简体搜索词双向兼容。
- **高性能异步切片与缓存**：采用惰性实例化、状态缓存、向量多级缓存与 `requestAnimationFrame` 帧级防抖，保持轻量高效与 60FPS 丝滑体验。

## 安装方式

通过 Tampermonkey / Violentmonkey 等油猴插件加载 `bilibili-search-cleaner.user.js`。
