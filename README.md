# Bilibili 去掉搜索无关视频

自动隐藏 Bilibili 搜索结果中不包含关键词的无关视频，支持 `@UP主` 定向筛选、`-排除词` 与 `#Tag` 专项筛选，净化搜索结果。（支持简繁中文归一化匹配）

## 功能特性

- **广告与推广卡片剔除**：精准屏蔽搜索流中的推广视频、商业广告及小火箭推荐卡片。
- **关键词严格筛选**：隐藏标题中不包含搜索词的无关视频。
- **高级语法过滤**：
  - `-排除词`：排除标题包含指定词汇的视频（如 `进击的巨人 -解说`）。
  - `#Tag`：基于视频标签分类进行筛选。
  - `@UP主`：仅保留特定 UP 主发布的视频。
- **简繁归一化**：内置 OpenCC 繁简转换引擎，繁体与简体搜索词双向兼容。
- **高性能 DOM 判定**：通过状态缓存与 `requestAnimationFrame` 节流，避免重复计算。

## 安装方式

通过 Tampermonkey / Violentmonkey 等油猴插件加载 `bilibili-search-cleaner.user.js`。
