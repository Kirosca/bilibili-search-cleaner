# Bilibili 去掉搜索无关视频 (v3.1.0)

基于 Bilibili 搜索页的增强与净化脚本：默认屏蔽商业推广/广告卡片，提供 **12 维视频品质分类与筛选**、**无缝瀑布流自动翻页**、**搜索条件常驻** 以及 **`@UP主` / `-排除词` / `#Tag` 精准语法过滤**（内置 WBI 签名协议栈与 OpenCC 简繁归一化）。

---

## 核心特性 (v3.1.0)

- **视频品质评价与筛选体系**：
  - 依据播放、点赞、收藏、弹幕、评论与时长等指标，自动为视频计算评分并划分品质等级（🏆 殿堂神作、💡 硬核干货、⭐ 高口碑佳作、🏅 综合标杆、💎 冷门宝藏、🍀 稳健良作、💥 话题焦点、💬 激辩热议、🔥 弹幕密集、⚡ 爆款短片、🌱 样本较少等）。
  - 视频封面左上角展示品质胶囊勋章与参考评分，支持「📑 全部展示 / ✨ 仅精选」切换。
  - 在 `/all`（综合）与 `/video`（视频）搜索页的条件区注入「🏷️ 视频品质」药丸筛选栏，支持**单选、`Ctrl` 多选、`Shift` 范围连选**。
- **无缝瀑布流引擎**：
  - 内置纯前端 WBI 签名算法（纯 JS MD5 + 64 字节字符混淆映射），直接请求 B 站 `/x/web-interface/wbi/search/type` 接口。
  - 响应式自适应栅格步长（根据当前物理列数 4~7 列自动按 6 行计算单页容量 24~42 条）。
  - 采用 Vue 风格生命周期控制器，仅在 `/all`、`/video` 路径且 URL 含有效 `keyword` 参数时自动挂载；支持 `IntersectionObserver` 触底预加载与右下角悬浮徽标（**左键暂停/继续，右键平滑回顶**）。
- **实时检索反馈与广告屏蔽**：
  - 预注入 CSS 与响应脱壳双重拦截，秒杀商业推广与小火箭广告卡片。
  - 触底加载时动态展示已检索原始视频条数，避免静态提示带来的假死感。
- **快捷键支持**：
  - `/`：快速聚焦搜索框。
  - `Alt + Q`：快速切换搜索语法过滤并弹出状态提示。

## 油猴菜单配置

点击浏览器右上角油猴插件图标即可按需开关各项功能：

- ⚡ **一键全开/全关**：一键同步开关所有核心功能。
- ⚓ **搜索筛选常驻**（默认开启）：自动展开并维持搜索筛选条件面板常驻。
- 🌊 **无缝瀑布流**（默认开启）：流式滚动加载下一页视频，替代传统底部分页器。
- 🗝️ **搜索语法过滤 (Alt+Q)**（默认关闭）：按关键词、`-排除词`、`#Tag`、`@UP主` 过滤视频。
  - └─ **虚化显示模糊内容**（默认开启，语法过滤开启时可见）：开启时半透明去色虚化未匹配卡片（支持悬停查验）；关闭时直接物理隐藏。
- 🏷️ **视频品质标签**（默认开启）：开启封面品质勋章与品质筛选栏。
  - ├─ **标签可见范围**：切换「📑 全部展示」或「✨ 仅精选」。
  - └─ **封面显性评分**（默认开启）：控制是否在封面胶囊中显示数值评分。

## 筛选语法与安检规则

- **普通词**：标题必须包含该词（如 `数码`）。
- **`-排除词`**：标题中绝对不能出现该词，一票否决（如 `-开箱`）。
  - 发送给 B 站接口前会自动剥离排除词，最大化召回候选集合后再在本地进行二次物理过滤。
- **`#Tag` 标签筛选**：视频元数据与后台标签中必须包含该标签（如 `#评测`）。
- **`@UP主` 定向筛选**：投稿作者必须包含指定 UP 主名称（如 `@影视飓风`）。
- **全角与中文标点容错**：自动兼容中文输入法下的全角标点（如 `“ ”`、`＃`、`＠`、`－`）。
- **简繁归一化**：内置 OpenCC 繁简转换引擎，繁体与简体搜索词双向兼容。
