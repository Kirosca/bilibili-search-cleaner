# Bilibili 去掉搜索无关视频

自动隐藏 Bilibili 搜索结果中不包含关键词的无关视频，支持 `|` 条件或者匹配、`@UP主` 定向/精确筛选、`-排除词` 与 `#Tag` 模糊/精确筛选，彻底净化搜索体验。（支持简繁中文归一化匹配）

## 功能特性

- **广告与推广卡片剔除**：精准屏蔽搜索流中的推广视频、商业广告及小火箭推荐卡片。
- **高级筛选语法（支持多级组合与 `|` 或者分支）**：
  - **`|` 条件分支（或者）**：支持在所有语法间使用，如 `A | B`（标题包含 A 或 B）、`@A | @B`（UP 主包含 A 或 B）、`#"A" | #"B"`（标签精准匹配 A 或 B），支持多个 `|` 连续串联。
  - **`#"Tag名"` 精确标签**：要求视频标签与引号内内容**完全一致**（如 `#"DeepSeek V3"`），区分于普通包含匹配 `#Tag`。
  - **`-#Tag` 与 `-#"Tag名"` 标签排除**：
    - `-#Tag`：排除包含指定标签字面的视频（如 `-#手游`）。
    - `-#"Tag名"`：排除标签与引号内完全一致的视频（如 `-#"英雄联盟"`）。
  - **`@"UP主"` 与 `-@UP主` / `-@"UP主"` UP主筛选与排除**：
    - `@UP主`：UP 主名称包含指定文本（如 `@影视`）。
    - `@"UP主"`：UP 主名称**完全匹配**指定文本（如 `@"老番茄"`）。
    - `-@UP主`：排除 UP 主名称包含指定文本的视频（如 `-@营销号`）。
    - `-@"UP主"`：排除 UP 主名称完全等于指定文本的视频（如 `-@"某UP"`）。
  - **`-排除词`**：排除标题中包含指定词汇的视频（如 `进击的巨人 -解说`）。
- **复合语法支持**：支持空格与 `|` 嵌套组合（如 `A B | C D -#E`），即 `(A 且 B) 或 (C 且 D)，并排除标签 E`。
- **全角与中文标点容错**：自动兼容中文输入法下的全角标点（如 `“ ”`、`｜`、`＃`、`＠`、`－`）。
- **简繁归一化**：内置 OpenCC 繁简转换引擎，繁体与简体搜索词双向兼容。
- **高性能 DOM 判定**：通过状态缓存与 `requestAnimationFrame` 节流，避免重复计算。

## 安装方式

通过 Tampermonkey / Violentmonkey 等油猴插件加载 `bilibili-search-cleaner.user.js`。
