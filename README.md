# Bilibili 去掉搜索无关视频（fuse.js）

自动隐藏 Bilibili 搜索结果中不包含关键词的无关视频，支持 Fuse.js 模糊匹配、`@UP主` 定向筛选、`-排除词` 与 `#Tag` 专项筛选，净化搜索结果。（支持简繁中文归一化匹配与测试模式预览）

## 功能特性

- **Fuse.js 模糊容错匹配**：引入轻量级 Fuse.js，支持关键词拼写轻微错误、同音/形似字模糊匹配，避免误杀。
- **测试模式（被过滤视频预览）**：右下角提供浮动统计胶囊。点击可实时在页面中展开被过滤视频，附带红色虚线高亮与具体过滤原因角标（未命中关键词、排除词、未匹配标签、非目标UP主），悬停可临时恢复清晰度。
- **广告与推广卡片剔除**：精准屏蔽搜索流中的推广视频、商业广告及小火箭推荐卡片。
- **高级语法过滤**：
  - `-排除词`：排除标题包含指定词汇的视频（保持严格匹配，避免误屏蔽）。
  - `#Tag`：基于视频标签分类进行筛选。
  - `@UP主`：仅保留特定 UP 主发布的视频。
- **简繁归一化**：内置 OpenCC 繁简转换引擎，繁体与简体搜索词双向兼容。
- **高性能 DOM 判定**：采用惰性实例化、状态缓存与 `requestAnimationFrame` 节流，保持轻量高效。

## 安装方式

通过 Tampermonkey / Violentmonkey 等油猴插件加载 `bilibili-search-cleaner.user.js`。
