三、搜索语法、简繁与底层防误判守卫

普通词 视频标题必须包含全部普通词（逻辑 AND）。
-排除词 标题包含即一票否决；发往 B 站接口前自动剥离该词，最大化召回候选集。
@UP主 限定第一署名作者名称包含指定词（去除合作者后缀）；接口前剥离 @。
#Tag 限定后台 Tag/分类字段包含全部标签；兼容未编码 # 截断进 location.hash 的拼回。
底层增强守卫：
• 繁简与实体归一：接入 OpenCC (t2cn) + jsdelivr 动态保底脚本，自动反转义 &quot;/&#x27; 等实体与中文单引号。
• 防提前锁死：仅当 isTagReady && isStatReady 均满足时才写入 data-purified-query 缓存。
• 直播/活动/外部隐藏隔离：跳过 .activity-game-list 与广告卡；三重识别直播卡（.bili-live-card / live.bilibili.com / living），并在接口写入阶段跳过 live_room，彻底杜绝直播卡误标“样本较少”。

四、快捷键、品级栏交互与动态计数

/
非输入框聚焦状态下快速聚焦搜索框，并阻止 / 字符输入。
Alt + Q
非输入状态下瞬切【搜索语法过滤】（已拦截 Mac Option+Q 输出 œ），并在左下角弹出 1.5 秒轻量 Toast 提示（瀑布流开启时自动上移至 bottom: 72px 避开页码徽标）。
顶部【品级标签】类文件夹式交互：
• 单击：单选某品级并设锚点（点击【全部】重置）。
• Ctrl / Cmd + 单击：独立多选 / 反选。
• Shift + 单击：从锚点到当前项闭区间范围连选（配合 Ctrl 可叠加）。
• 瀑布流补屏：筛选后若当前屏幕可视卡片 < 10 张且已开瀑布流，自动触发 triggerLoadNextPage() 静默补拉。
动态按钮计数规则： 仅当【搜索语法过滤】与【虚化显示模糊内容】同开时显示 (非灰色/总数)；其余模式仅显示 (当前可见数)；无命中项自动置灰（opacity: 0.55），且通过 data-external-hidden 排除广告/原站隐藏节点，切换筛选总数零跳变。

五、无缝瀑布流与纯前端 WBI 签名协议栈

WBI + IntersectionObserver
1. WBI 鉴权与密钥同步

内联轻量 MD5（computeMd5）与 64 字节混淆映射表（mixinKeyEncTab），优先从首屏 __INITIAL_STATE__.wbi_img 零请求取钥，兜底拉取 /x/web-interface/nav，直连 /x/web-interface/wbi/search/type。

2. 自适应步长与模板克隆

仅测前两行计算物理列数（4~7 列）× 6 行 = 单页拉取 24~42 条；缓存预清洗后的母卡骨架（移除直播播放器与 SponsorBlock 角标），以 seenBvidMap 去重并在入树前增量安检。

3. 并发防串台与风控自愈

isPaging + AbortController + pagingSessionSeq 彻底掐断切词旧请求；劫持 pushState/replaceState；分页器 isConnected 脱落自动重绑；捕获 -412/-403 风控码并支持点击重试。

左下角悬浮徽标：内联微软 Fluent SVG 波浪图标，依据当前可见视频物理行数（每 6 行为 1 页）实时计算并展示 第 X/Y 页；左键暂停/继续，右键平滑回到顶部。
底部加载提示条：实时反馈已检索原始视频数（正在筛选... (已检索 N 条)），触底自然结束或异常时提供点击重试。

🏆 殿堂神作 T0 顶峰

⚡ 爆款短片 T0/T1 短片

💡 硬核干货 T1 收藏向

⭐ 高口碑佳作 T1 好评向

经时长加权后赞播比突出的高认可度作品，观众普遍给予正面好评。

赞播比与藏播比双优均衡，无明显短板的全面扎实水准。

播放量在 1000~2万之间的中小样本高纯度遗珠，适合挖掘被埋没的佳作。

播放 ≥ 3000 且未触碰低质预警线，亦未落入高阶或热议象限的常规健康内容，作为可靠基本盘。
