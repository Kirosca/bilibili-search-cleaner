2 perfFloor 区间拉伸原理与实时打分模拟器

若直接用全站表现率 perfRatio，进入殿堂神作的视频全挤在 0.50~0.95 后半段窄缝里。引入品级起步线 perfFloor 做归一化重映射 (perfRatio - perfFloor) / (1 - perfFloor)，把有效差距完整铺开到 0 ~ floatMax 全幅跨度。

3 归一化权重与 12 维品级判定顺序

⏱️ 时长权重 durFactor

以 5 分钟为基准：clamp(sqrt(时长分钟 / 5), 0.4, 2.0)。短视频适度折减，长篇精作最高享 2 倍加权。

▶️ 播放量权重 playFactor

5 万以下 1.0x；超过 5 万按 min(1.4, 1.0 + 0.2 * log10(播 / 50000)) 对数补偿，500 万封顶 1.4x。
