Pain Points Solved

直击 B 站搜索 6 大顽疾

每一项功能都来自真实高频搜索场景，不堆砌花哨无效的装饰

🗝️

精准搜索语法 + 智能脱壳

痛点：B站不支持减号排除、#Tag 与 @UP主 联合过滤

支持 -排除词、#标签、@UP主。发送给 B 站接口时自动“脱壳”保证召回率，前端再精准拦截；并内置 OpenCC 简繁归一化，简繁互搜零障碍。

🏆

12 维品质评级 + 避坑雷达

痛点：只看播放量易被标题党骗点击，好内容被埋没

直接读取点赞、收藏、弹幕、评论、时长与分区，经过时长加权与高播放稀释修正，给出「殿堂神作 / 硬核干货 / 冷门宝藏 / 谨慎观看」等 12 类勋章及 0~100% 参考分，悬停可见明码加减分明细。

🌊

Wbi 驱动无缝瀑布流

痛点：过滤后单页视频变少，反复翻页打断沉浸感

原生 Wbi 签名自动请求下一页并去重拼接，动态适应列数布局。右下角悬浮微标实时显示「当前视口第几页」，支持左键暂停/继续、右键平滑回顶。

👁️

虚化保留 vs 物理隐藏

痛点：一刀切隐藏怕误杀，全保留又太眼花

开启「虚化显示」后，未命中视频降为 16% 透明度并去色占位，鼠标悬停即刻恢复清晰查验；通过根类名 O(1) 瞬时切换，千张卡片零重算不卡顿。

🛡️

接口 + CSS 双层去广告

痛点：商业推广、小火箭推广混在视频流里

在网络响应与 SSR 数据层物理剔除 is_ad_loc / is_promoted，同时预注入 :has() CSS 规则在渲染前秒杀推广卡片。

⚡

筛选常驻 + 快捷键 + 性能

痛点：筛选面板默认折叠、长列表滚动掉帧

自动展开并锁定筛选面板；支持 / 聚焦搜索框、Alt+Q 秒切过滤；配合 content-visibility: auto 离屏优化，刷千条依然丝滑。
