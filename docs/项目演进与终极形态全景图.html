🗝️ 搜索语法解析与脱壳

支持普通词、-排除词、#Tag、@UP主 与简繁归一化，自动改写后端参数并重算 Wbi 签名。

🛡️ 网络层 + SSR 双路拦截

结合 Pinia/SSR 首屏轮询与 fetch 劫持，接口级物理剔除广告并采集全量赞/藏/弹/评指标。

🔍 DOM 五道安检与吸顶

幂等缓存 + 数据就绪门控，区分语法淘汰（虚化/隐藏）与品质淘汰（物理隐藏），筛选栏滚动吸顶常驻。

🏆 12 维品质 + 三层评分

时长与播放量双修正，12 象限漏斗分级 + 0~100 健康度评分（品级底分 + 拉普拉斯平滑表现分 + 词条）。

🌊 WaterfallLifecycle 瀑布流

统一生命周期状态机、sessionSeq 防竞态锁、-412/-403 风控熔断与 60ms 连贯续载。

入口与语法解析 数据采集与去广告 安检过滤与判定 品质评分与瀑布流状态机
