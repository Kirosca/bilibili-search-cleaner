节点详情

WaterfallLifecycle.sync(reason)
阶段 2 · 生命周期调度

瀑布流唯一外部调度入口。所有页面事件只负责上报 reason，由状态机根据当前挂载状态自动决定挂载、更新或卸载。

  • 未挂载 + 准入通过 → onMounted()
  • 已挂载 + 准入不通过 → onUnmounted()
  • 已挂载 + 准入通过 → onUpdated(reason)
