Release Upgrade Guide / Changelog

Bilibili 搜索净化 — v3.0.0 到 v3.1.0 升级说明

v3.0.0 (3,169 行) → v3.1.0 (3,672 行)

本次升级从 v3.0.0 演进至 v3.1.0，重点引入 0~100 封面显性综合参考分 与 三层算分模型，精调多维度品级判定规则，调整默认开关策略，并针对高频瀑布流滚动与 SPA 渲染进行了系统性性能优化。

01 · 封面显性评分
三层打分模型上线

品级底分 + 赛道浮动 + 明码词条加减，支持独立开关控制显隐。

02 · 判定规则精调
分区权重与防误判

干货/娱乐分区微调、干货藏赞比隔离、长视频避坑放宽、新增样本较少筛选。

03 · 性能与内存治理
增量监听 + 有界缓存

增量 MutationObserver、5000 条 Map 上限、行号与关键词缓存。

04 · 默认配置重塑
开箱体验调整

默认开启瀑布流、虚化与全部标签展示；搜索语法过滤改为默认关闭。

2 核心新增：封面显性评分与三层算分模型

胶囊展示对比（右侧新增 .bili-cleaner-badge-score）
除 q-low-sample（样本较少）外，其余 11 个品级均支持在胶囊内直接展示 0~100 综合参考分。
👑 镇站神作 94 📚 一流干货 78 💎 冷门宝藏 74 🌱 样本较少
第一层 · 品级基础底分
SCORE_TIER_BANDS

为 12 个品级设定独立的底分 base 与分数上下限 [min, max]（如避坑 0~20、常规 22~58、佳作 60~88、神作 68~98），防止不同品级分数倒挂。

第二层 · 赛道表现浮动分
HEALTH_SCORE_TRACKS

按赛道（干货重收藏 55%、短片重赞 55% 且无时长惩罚、弹幕重密度 55%、论战重评论 55%）计算表现分，并通过 [perfFloor, perfCeil] 拉伸同品级内部跨度。

第三层 · 明码词条加减分
computeScoreBreakdown

叠加 20 余项明码词条（如三连拉满 +3、压箱宝典 +4、现象级破圈 +4、三年经典 +4、新片冷静 -3、标题党预警 -3 等），正向词条净加分封顶 +12。

📐 高播放量稀释修正（playFactor）

新增于 computeQualityMetrics：播放量 ≤ 5 万权重为 1.0x；超过 5 万后按对数平滑补偿破圈稀释（50 万约 1.20x、500 万约 1.40x，5000 万封顶 1.60x），与时长修正 durFactor（0.4~2.0x）共同参与归一化指标计算。

💬 悬浮明细与元数据扩展

videoStatMap 新增记录 typename（分区）与 pubdate（发布时间）。悬停封面胶囊可查看分区、播放权重、发布日期及完整评分拆解；且改用 DOM element.title 属性写入，修复长文本中引号截断提示的问题。

3 12 维品质判定与筛选栏精调

1. 分区与教程意图轻量微调
  • 识别干货分区（HARDCORE_BOOST_ZONE_RE）、教程关键词（TUTORIAL_INTENT_RE）与纯娱乐分区（ENTERTAINMENT_ZONE_RE）。
  • 干货/教程向门槛放宽为 0.85x，纯娱乐区收紧为 1.15x。
  • 干货/教程区评论区多为求资源或问报错，争议对线判定阈值从 10% 提高至 18%；娱乐区弹幕密度门槛上调 15%。
2. 一流干货（q-hardcore）藏赞比隔离
  • 新增 favLikeRatio（收藏/点赞比）校验，常规分区要求 ≥ 0.40，干货区放宽至 0.30，娱乐区收紧至 0.55。
  • 避免高赞低收藏的纯娱乐/擦边视频误入「一流干货」分类。
3. 长视频避坑线（q-warning）放宽
  • 时长 ≤ 15 分钟维持原标准（赞播比 < 1.2% 且 藏播比 < 0.5%）。
  • 时长 > 15 分钟的长视频放宽至赞播比 < 0.5% 且 藏播比 < 0.2% 才触发避坑预警，减少长教程或录播被误判。
4. 冷门宝藏下探与筛选栏补全
  • q-hidden-gem 新增 1000 ~ 3000 播放量且高赞/高藏高纯度的极小样本破格通道。
  • 顶部品质筛选栏（QUALITY_CATEGORY_KEYS）新增 🌱 样本较少（q-low-sample）选项，并在各筛选按钮悬浮提示中附带对应赛道的【参考分权重】。

4 性能优化与工程稳定性改进

⚡ 增量 MutationObserver

新增 isCleanerOwnNode 跳过脚本自身注入的 Toast、悬浮徽标、筛选栏等节点；仅收集新增卡片节点传入 filterDOMElements(addedNodes) 做增量处理，并配合 seenBatchCards 去重。

🧠 有界缓存防内存泄漏

新增 setBoundedMap（上限 MAX_CACHE_MAP_SIZE = 5000），约束 videoTagMap 与 videoStatMap 体积，长时间瀑布流无限滚动后自动淘汰最旧条目。

📏 卡片行号与页码缓存

新增 recomputeCardRows 与 cachedVisibleCards，仅在 DOM 增删、筛选切换或窗口缩放时重算卡片物理行号 _wfRow，滚动期间不再全量读取离屏节点几何属性。

🔍 搜索词与繁简转换缓存

getSearchKeywords 增加基于 search + hash 的结果缓存；toSimplified 增加纯 ASCII 快速通道，英文/数字文本直接返回，跳过 OpenCC 开销。

🔑 WBI 签名与筛选切换提速

cachedWbiKeys 预计算并缓存 mixin_key；点击品质筛选标签时优先基于已缓存的分类直接切换卡片显隐，仅对未就绪卡片补跑增量安检。

🧹 细节清理与日志收敛

广告剔除逻辑增加 hasAdRemoved 守卫，仅实际移除广告时打印日志；瀑布流克隆卡片移除了原 v3.0.0 中针对 sponsorThumbnailLabel 的额外移除逻辑。
